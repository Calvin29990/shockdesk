# Écarts vs l'ébauche (PROGRAMME DE PRÉPARATION INTENSIF.pdf)

L'ébauche est bonne comme ossature (bilingue, 4 blocs, ShockDesk, Python).
Elle ne produit pas un candidat élite sur *ce* Drive.

## Ce qui cassait l'objectif « 100 % du Drive »

| Dossier Drive | Dans l'ébauche | Réalité |
|---|---|---|
| EXOTICS & OPTIONS (15 fichiers) | 1 semaine Hull + structures vanille | de Weert, Bouzoubaa ×2, Gatheral, Bossu/Carr, barrières, Clark FX, convertibles, Natenberg, Ramirez **absents** |
| WORDS (13 fiches entretien) | « interview mode » générique | Banque réelle jamais assignée jour par jour |

| COMMO (4) | 0 | Cotton + options commo + WASDE — unique angle différenciant |
| QUANT (10) | proba / OLS / MC / VaR génériques | Joshi, Wilmott, matrix cookbook, Why Quant |
| ShockDesk | onglets **ALM, Risk, Gallery 20 smiles / 10 autocalls** | **Ces onglets n'existent pas.** Un élite ne promet pas un outil qu'il n'a pas. |

## Ce qui cassait le rythme

- 7 jours off (jeudi + dimanche) sur 27 = trop pour un sprint élite.
- 4 h/j × 20 j = 80 h. Le Drive fait ~61 ressources. 80 h de lecture
  linéaire = survol. 5 h 30 ciblées × 22 j = **121 h** : extraction + oral
  + code + lab, pas lecture de couverture à couverture.
- Python 30 min collé en fin de journée : le code devenait optionnel.
  Ici le livrable Python *est* le ticket de sortie du jour.
- Stage non coupé : l'ébauche laissait de la place mentale aux candidatures.

## Ce qui est conservé

- Bilingue FR/EN sur chaque oral.
- ShockDesk comme simulateur, pas comme alibi.
- Découpage vanille → exotique → taux/ALM → synthèse.
- Fiche de suivi recollable dans le chat.
